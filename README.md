# Resona — landing page

Static landing page for Resona, the synthetic customer research lab.

- `index.html` — the whole site (self-contained; loads DM Sans/DM Mono from Google Fonts and Lenis from unpkg)
- `vercel.json` — static hosting config

## Deploy
Import this repo in Vercel (Framework preset: **Other**, no build command, output directory `.`). Every push to `main` redeploys.
